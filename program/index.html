Program

決められずにいることを、
自分の基準で決めるために。

Pale Hourでできることは、3つです。
無料の診断で今の位置を知る。60分の個別相談で、決めることを1つに絞る。3か月で、それを決め切る。

Journey

Pale Hourでの進み方

どこで止めても構いません。診断だけ、個別相談だけのご利用でも大丈夫です。

  1. Start

    InstagramやThreadsで出会う

    日々の発信を読んで、「これは私のことかもしれない」と思ったら。

  2. Step 01 — 無料

    恋愛フェーズ診断

    6つの質問で、今の恋愛の状態を5段階で見ます。Midnight / First Light / Turning Tide / Sunrise / Morning Tide。結果はLINEでお受け取りいただけます。

  3. Step 02 — 10,000円

    個別相談（60分）

    いま決められずにいることを全部出して、1つに絞ります。「◯月◯日までに、AかBか」の1文にして終わります。

  4. Step 03 — 3か月

    決め切る3か月

    あなたの判断基準（トリセツ）を作り、その基準で実際に決めます。決めるのはあなたです。私は決めません。

提供プログラム

無料
01

恋愛フェーズ診断

6問・約1分。相手の返事や機嫌で、今日の予定が変わっていないか。今の自分の位置を知るところから始めます。診断結果は医学的・心理学的な診断ではなく、自己理解のためのセルフチェックです。

診断をはじめる
60分 / 10,000円
02

個別相談

ビデオ通話で60分。決められずにいることを全部出して、いちばん先に決めることを1つに絞ります。終わりに「今日できたこと／いま扱う決断／次にやること」の3行をお送りします。決め切る3か月は、この相談のあとにご案内します。

個別相談を申し込む
3か月 / 150,000円〜
03

決め切る3か月

この人と続けるか、終わらせるか。いちばん切実で、いちばん決められないことを1つ、3か月で決め切ります。プランは2つです。
Pale Note（150,000円）＝録画を見てあなたが書き、私が読んで返します。
Pale Book（500,000円）＝個別コンサル3回で、私があなたを読んで書き、冊子にします。
決まらなければ、条件つきで最長4週延長します（追加のお代はいただきません）。
